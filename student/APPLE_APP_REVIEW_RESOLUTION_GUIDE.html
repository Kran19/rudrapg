3. Developer Build & Upload Instructions

Follow these steps to archive and upload build 1.0.1 (2) to App Store Connect:

Step 3.1: Clean and Fetch Dependencies

cd student
flutter clean
flutter pub get

Step 3.2: Verify Version in pubspec.yaml

Confirm that line 19 of student/pubspec.yaml contains:

version: 1.0.1+2

Step 3.3: Build iOS Release Archive

Option A (Command Line):

flutter build ipa --release

The archive will be output to: build/ios/ipa/rudraboyspg.ipa

Option B (Xcode GUI):

  1. Open student/ios/Runner.xcworkspace in Xcode.
  2. Select Any iOS Device (arm64) as the build target.
  3. Go to Product → Archive.
  4. When the Organizer appears, click Distribute App → App Store Connect → Upload.

Step 3.4: Processing in TestFlight

  1. Log into App Store Connect → TestFlight.
  2. Wait 5–10 minutes until build 1.0.1 (2) finishes processing.
  3. If prompted for Missing Export Compliance, select No (Standard HTTPS encryption) and save.
